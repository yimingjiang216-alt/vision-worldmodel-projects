# VideoDiT - 动作条件视频生成

从零实现的动作条件视频扩散模型（Video Diffusion Transformer）。

状态：代码整理中。训练在 Kaggle 上完成，本机暂无完整副本，正在合并整理。

---

## 做了什么

从零实现模型与训练循环，不依赖现成的视频扩散框架：

- **模型**：视频切 patch 成 token 序列，堆叠多头自注意力 DiT Block；
  时间步经正弦编码注入；逐帧动作经 MLP 编码后由 adaLN-zero 注入各 Block，
  以零初始化 FiLM 调制 token。
- **采样**：DDPM / DDIM，以及 Classifier-Free Guidance。
- **训练目标**：扩散目标由 ε 预测改为 x0 预测。

## 结果

| 项目 | 数值 |
|---|---|
| 参数量 | 3.0 M |
| 分辨率 / 帧数 | 48 x 48 / 16 帧 |
| 训练轮数 | 240 epochs（16 帧模型） |
| 动作响应 / 噪声比 | 1.67 x（CFG = 16） |

训练目标从 ε 预测改为 x0 预测后，纯噪声生成的 MAE 由 0.42 降到 0.135。

## 动作可控性怎么定量评估

没有用现成的视频质量指标，而是自己设计了一个判据：

- 用相位相关估计帧间位移；
- 做两组对照：「固定噪声、只改动作」与「固定动作、只改噪声」；
- 以两者的消融比作为动作可控性的判据。

## 其他

- CFG dropout 由 0.15 提到 0.25 并续训，是这一步让 16 帧模型的响应比达到了判据要求。
- 模型已导出 ONNX，用 onnxruntime-web 在浏览器里跑完整的 DDIM 采样，
  做成无需后端的交互式页面。
