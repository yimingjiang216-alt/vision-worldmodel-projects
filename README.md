# vision-worldmodel-projects

从图像到可漫游的三维场景（mini 空间智能 / 世界模型方向）。

输入：手机或无人机拍摄的多视图影像
输出：一段可沿自定义相机轨迹"飞过"的新视角视频

## 思路
多视图影像 → COLMAP 恢复相机位姿与几何 → 3D Gaussian Splatting 重建场景 → 自定义轨迹渲染新视角视频

## 为什么做
对应"空间智能 / 世界模型"方向：先用几何与神经渲染把真实场景变成可漫游的 3D 表示，再把过程中产出的位姿、深度、点云作为条件，探索接入视频生成。

## 目录（随开发补充）
```
data/       采集的影像
colmap/     SfM 预处理脚本与结果
train/      3DGS 训练与渲染脚本
eval/       指标评测（PSNR / SSIM / LPIPS）
```
